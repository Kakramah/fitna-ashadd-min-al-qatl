# الفتنة أشد من القتل

رسالة عربية مستقلة مبنية بإيقاع القالب 12 من مكتبة خلدون. افتح `index.html` في المتصفح، أو شغّل خادماً محلياً من هذا المجلد لمعاينة كل المزايا.

كل الصور الثلاث تصورات مولدة لهذا المشروع وليست توثيقاً لحوادث. مصادر الآية والإشارة الأممية في `sources.json` وفي نهاية الصفحة. الترجمة العربية للإشارة الأممية صياغة تحريرية وليست اقتباساً حرفياً.

الخطوط المحلية Amiri وNoto Naskh Arabic وIBM Plex Sans Arabic بترخيص SIL OFL؛ نصوص التراخيص في `fonts/`. العقاب أصل هوية المستخدم، وليس أصلاً حراً لإعادة الاستخدام.
